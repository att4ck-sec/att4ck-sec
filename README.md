🛡️ Att4ck-Sec (V1 Ultimate Predator)
​Automated Subdomain Discovery & Vulnerability Scanner
​🌟 About the Project
​Att4ck-Sec is an advanced reconnaissance and vulnerability scanning tool specifically designed for Bug Bounty hunters and Cybersecurity professionals. It streamlines the initial phase of security testing by automating the discovery of an organization's digital footprint and scanning for potential security flaws.
​🚀 Key Features
​Subdomain Enumeration: Integrates high-performance tools like Subfinder and Assetfinder to find hidden subdomains.
​Active Host Probing: Uses httpx to filter and identify live, reachable targets from the discovered domains.
​Automated Scanning: Leverages Nuclei with specialized templates to detect critical vulnerabilities and misconfigurations automatically.
​Output Management: Generates organized, clean text files for each stage of the recon process for further analysis.
​🛠️ Installation & Usage
​To run the tool on Kali Linux or any Linux-based system, follow these steps:
# 1. Clone the repository
git clone https://github.com/att4ck-sec/att4ck-sec.git

# 2. Navigate to the project directory
cd att4ck-sec

# 3. Run the Predator Recon tool
python3 att4ck_sec.py
